# Using the web build

This guide is for the Pack 137 News Builder. It is also inside the zip file, as `HOW-TO-USE.md`.

You do not need to install anything. You do not need to know HTML.

## What you need

- A computer with one of these web browsers, in its latest version: Google Chrome, Microsoft Edge, Mozilla Firefox or Apple Safari.
- The zip file from the project owner or the pack.
- The internet is not needed to use the tool once you have unzipped it and opened it.

## Step 1: Unzip the file

On Windows:

1. Find the zip file. It is often in your Downloads folder.
2. Right-click the file. Choose Extract All.
3. Choose Extract. A new folder opens.

On a Mac:

1. Double-click the zip file. A folder with the same name appears next to it.

## Step 2: Open the tool

1. Open the folder you just made.
2. Double-click the file called `index.html`.
3. The tool opens in your web browser.

If the file opens in another program, right-click `index.html`. Choose Open with, then pick your browser.

Do not open the tool from inside the zip window. Unzip the file first.

The address bar may start with `file://`. This is normal for this tool.

Keep the folder. Do not delete it while you are using the tool.

## Where your work is saved

- Your work is saved in your web browser, on this computer only.
- The tool never sends what you paste or type to the internet, to the pack or to another computer.
- On the monthly letter screen, the words "Saved on this device" show that your work has been saved.
- Your saved work does not move to another computer. A different browser on the same computer does not see it either.
- In Chrome, every file you open from a folder on this computer shares the same saved work. So a second copy of the tool, opened from another folder in Chrome, can show the same saved work.
- Because of that, any other web page file you open from your computer in the same browser could read your saved letter or change your saved settings. Only open web page files you trust in that browser. If the tool ever says your settings were changed outside it, open Settings and check them, or press Restore Pack 137 defaults.
- Clearing your browser's history or site data can delete saved work.

## Keep a copy with Download draft

Download draft is on the monthly letter screen.

1. Press Download draft.
2. Your browser saves a file that ends in `.json`. Save it in a folder you can find again.
3. To carry on later, press Open draft and choose that file. You can do this on this computer or on another one.

When you come back on the same computer and browser, the tool offers to keep working, to start next month's letter from this one, or to start a blank letter. Download a draft as well, so you have a copy if the browser's saved work is ever cleared, or to carry on from another computer.

For an announcement, the tool does not keep a copy for you. Copy the finished HTML into TroopTrack before you close the tool.

## Copy the HTML into TroopTrack

1. Press Copy new HTML for an announcement, or Copy letter HTML for the monthly letter.
2. In TroopTrack, open the message. Press the `<>` button to open code view.
3. Delete the old code in code view. Paste the new code.
4. Save.

If the Copy button does not work, the tool shows the code in a box. Click inside the box. Press Ctrl+A to select everything, then Ctrl+C to copy. On a Mac, use Command+A and Command+C.

## Spelling

- The tool does not check spelling. Your web browser does.
- A word with a wavy red line may be misspelled. Right-click the word to see suggestions.
- Pack names such as "Webelos" may show a red line. You can ignore it.
- Some browsers have an optional "enhanced" or cloud spell check (for example Chrome's Enhanced spell check, or Microsoft Editor in Edge). If you have turned it on, the browser itself may send what you type to its spelling service. The tool does not. Leave it off if you do not want that.

## Pictures in the preview

Photos do not show in the preview. Each photo shows as a grey box of the same size. This is on purpose. The tool does not load pictures from the internet. The copied code still includes each photo's address.

## Photos in the monthly letter

In the monthly letter, you do not paste a photo address. The tool leaves a spot for each photo. You put each photo in with TroopTrack's own editor after pasting, then use Finish photos to add the descriptions.

1. In the letter, add a Photo block, or turn on the photo in a Sidebar box.
2. Type the photo description. It tells people who cannot see the photo what it shows. Do not name a child. Add a caption if you want one.
3. If the photo file is big, press Shrink a photo for the letter and keep the small file it saves.
4. Press Copy letter HTML and paste it into TroopTrack, as usual.
5. In TroopTrack, replace each box that says Insert photo here with the photo, using TroopTrack's image button.
6. Open TroopTrack's code view, select all, and copy.
7. Back in this tool, scroll to Finish photos on the Monthly letter screen. Paste what you copied into the box.
8. Check the notes and the preview. Press Copy finished HTML.
9. In TroopTrack's code view, replace everything with the finished code, then save.

Finish photos adds each photo's description and makes the photos fit phone screens. It uses the descriptions you typed in the letter, in the same order as the spots.

The tool lists every photo spot in the "Things to look at" box, so you can check that none is left. A spot does not stop you copying.

An older saved draft may still hold a photo address. The tool shows that address as plain text, with a button called Use a photo spot instead. Pressing it removes the address and turns the photo into a spot. Undo brings it back.

## Shrinking a photo

Big photos from a phone or camera can be slow to upload. The tool can make a smaller copy for you. It does this on your computer. The photo is not sent anywhere.

1. Press Shrink a photo for the letter, next to a photo address. In the announcement, the button is called Shrink a photo.
2. Choose the photo from your computer or phone.
3. Wait for the button to say Shrink a photo again. Your browser saves a new file that ends in `-letter.jpg`. Look in your Downloads folder.
4. Upload that new file in TroopTrack. Copy its address and paste it into the photo address box.

The new copy is a JPEG, at most 1104 pixels wide and about 300 KB. Location and camera details are removed from it. Your original photo is not changed.

If the tool says it cannot read the photo, save or export the photo as a JPEG and try again. Some photo types, such as HEIC, only open in Safari. Photos over 50 MB are not opened.

## Undo and redo

- Ctrl+Z undoes your last change (Command+Z on a Mac).
- Ctrl+Shift+Z or Ctrl+Y redoes a change you undid (Command+Shift+Z on a Mac).

## Browsers that work

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Apple Safari

Use the latest version of each. Older versions may not show the tool correctly.

## If something looks wrong

- If buttons or colors look missing, check that you opened `index.html` from the unzipped folder. Try another browser from the list above.
- If your work seems to be gone, check that you are on the same computer and in the same browser. If you have a draft file, press Open draft and choose it.
- If you are still stuck, ask the project owner or the volunteer who gave you the zip.
